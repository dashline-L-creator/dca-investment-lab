# 在线网页与搜索收录

固定地址：**https://dashline-l-creator.github.io/dca-investment-lab/**

仓库首页的“打开最新网页”及About网站入口都指向这个地址。源码和历史版本按用户要求公开。

## 发布方式

GitHub Pages从独立的 `gh-pages` 分支根目录发布。该分支只放离线网页、第三方许可、校验摘要及索引文件，不复制研究脚本和开发资料。不需要个人令牌具备工作流写入权限。

更新前检查并生成分支：

```sh
python scripts/check.py
python scripts/prepare_pages.py
git push origin master gh-pages
```

每次推送 `gh-pages` 后由GitHub Pages构建，网址保持不变。发布后须检查Pages构建状态及线上版本号，不能仅凭源分支已推送就判定线上已更新。

## 搜索引擎

网页加入标题、内容简介、canonical链接、允许索引的meta标记与sitemap.xml，公开后具备被抓取的条件。项目路径下同时提供robots.txt；搜索引擎对域名根目录robots的规则仍由该域名决定。

公开访问不等于立即出现在搜索结果中。搜索引擎自行决定收录和排名，可能需要数天或更久，也不能保证。需要主动申请时，可在Google Search Console或Bing Webmaster Tools验证站点后提交站点地图：

`https://dashline-l-creator.github.io/dca-investment-lab/sitemap.xml`
