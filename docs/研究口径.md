# 研究口径与数据

每天在各标的实际交易日收盘投入50元人民币，包含起投日，最后估值日不再投入，连续满五年。允许小数份额，忽略费用与价差；累计收益率为期末总市值/总投入−1，未年化。

沪深300采用H00300全收益指数；其他采用场内ETF价格和现金分红再投资序列。人民币QDII ETF价格包含汇率、跟踪误差与溢价影响。拆分和停牌单独处理，基金内部费用已包含在价格中。

起投截止2021-10-31，估值覆盖至2026-10-31；最后实际交易日分别为2021-10-29和2026-10-30。七资产共15,354个五年滚动样本，一次选择四种进行比较。

## 冻结资料

- [`dca.json`](../data/research/dca.json)：完整网页数据，保持 v3.10 标签中 `work/v3.5/data.json` 的原始内容。
- [`manifest.json`](../data/research/manifest.json)：来源、SHA256及样本数。
- [`expected_stats.json`](../data/research/expected_stats.json)：原始统计基准。
- [汇总CSV](../data/research/exports/七资产各自全部历史统计.csv)、[全部样本CSV](../data/research/exports/七资产全部滚动样本.csv)：便于独立核验。

样本数组依次为起投日、估值日、投入次数、总投入、期末市值、累计收益率。分位数采用线性插值，总体标准差，最差5%均值取最低向上取整5%的样本。达标率使用收益率≥门槛，包含相等值。

相邻样本共享大量交易日，不能当作独立试验，历史频率不代表未来概率。
