# v3.11.0 本地动效迭代

日期：2026-11-26。此版本合并动效迭代与音乐需求，统一提交并准备发布。

入口：`dist/index.html`；离线留存包：`dist/dca-lab-v3.11.0.zip`。

## 本次变化

- 更新四资产对比时，保留相同资产的卡片节点，使用 GSAP Flip 过渡；新增“按收益排序 / 恢复资产顺序”。排序由点击触发，回放时不不断移动卡片。
- 历史路径采用 8 秒线性回放，沿真实日度数据逐段描绘。移动光点在相邻交易日之间线性插值，卡片和提示日期显示对应的实际日度记录；未平滑或改写数据。
- 播放位置增加细引导线与日期标签；本金虚线保留整个五年计划的参照路径。暂停保留位置，再次点击续播；拖动滑轨、更换起投日或切换视图会停止当前回放。
- 主界面标题使用 SplitText 分行显现，随后恢复现有的紫色流光；保留原开场 Logo。
- 手机卡片移动时间缩短至 0.36 秒。系统设置减少动态时，停止装饰动画，回放按钮直接展示完整结果；手动滑轨仍可研究任意时点。
- GSAP 3.13.0 Core、Flip、SplitText 内嵌于单文件网页，动画无需访问 CDN。Canvas 曲线采用 GSAP 驱动，无额外引入 SVG 曲线插件。

## 验证

完整检查通过，包括 15,354 个冻结样本及统计基准、原有二维/三维图表回归、新增七资产路径端点与 42 个绘图状态、暂停续播和减少动态回退。

浏览器实际检查：电脑与 390×844 手机布局；卡片排序、资产替换、中英文切换及回放暂停。未在实体手机进行验证。

源码及构建入口在当前工作区；独立 ZIP 包包含离线网页、许可证和使用说明。本次合并提交源码与构建产物，通过 gh-pages 分支发布；不创建 Release 附件。

## 背景音乐与常驻背景
顶部增加 Summer Ghost 网易云公开音源、播放/暂停、音量与原曲入口。封面静音，等待点击进入；点击时同步启动播放，被浏览器拦截时提示点击开启。循环播放，重播封面时音乐连续播放；页面后台时暂停，回到前台时按用户播放意愿恢复。音频不打入离线包，需联网。取消背景开关及旧的关闭偏好，保留系统减少动态支持。
